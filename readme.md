FLUX OS 
FLUX OS is a lightweight, browser-based desktop environment built from scratch using pure HTML, CSS, and JavaScript. It simulates a mini operating system right inside your web browser, complete with draggable windows, a taskbar, a start menu, and several built-in mini apps!

This is a beginner-friendly project created to practice front-end web development fundamentals without any complicated frameworks or build tools.

 What Can It Do?
Windows Management: Open multiple apps at once, drag windows around the screen, minimize them to the taskbar, maximize them fullscreen, or close them.

Start Menu & Search: Click the start button or press Ctrl + Space to open a searchable menu and launch your apps.

Built-In Mini Apps:

 Notes: Write and save notes (they even save automatically using your browser's local storage!).

 File Manager: Click through virtual folders like Documents, Pictures, and Downloads.

 Web Links: Quick-access shortcuts to popular websites.

 Calculator: A fully working mini calculator.

 Settings: Change your desktop background (black, white, or checker pattern).

 About: Learn more about the project and creator.

Notifications & Clock: Real-time digital clock in the taskbar and custom popup notification banners.

 Built With
HTML5 — For structure and layout.

CSS3 — For styling, flexbox/grid layouts, and retro monochrome aesthetics.

Vanilla JavaScript (ES6) — For all the interactive logic, DOM manipulation, pointer events (dragging windows), and saving data locally.

 How to Run It
Because this is a pure front-end project, you don't need to install Node.js, run servers, or configure anything complex!

Download or clone this project repository.

Make sure you have these three files in the same folder:

index.html

style.css

script.js

Simply double-click index.html to open it right in your web browser!

(Tip: If you use VS Code, you can also install the "Live Server" extension, right-click index.html, and select "Open with Live Server".)

 Keyboard Shortcuts
Ctrl + Space — Open/Close Start Menu

Escape — Close menus

 What I Learned Building This
Building FLUX OS was a great way to practice:

Handling DOM events (clicks, inputs, keyboard shortcuts).

Managing state in vanilla JavaScript (tracking open windows, active apps, and z-index layers).

Using CSS Custom Properties (variables) and media queries for responsive layouts.

Saving user data using localStorage.
